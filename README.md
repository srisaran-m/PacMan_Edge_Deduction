# Pac-Man Animation

A simple Pac-Man animation project built using **HTML, CSS, and JavaScript**.

The project demonstrates how JavaScript can be used to:

* Move an image dynamically across the webpage.
* Change Pac-Man images to create an animation effect.
* Detect the browser window boundaries.
* Reverse Pac-Man's direction when it reaches the edge.
* Use `setInterval()` to create continuous movement.
* Use JavaScript functions and arrays to control the animation.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How It Works

Pac-Man automatically moves across the screen and changes its image while moving. When it reaches the right or left edge of the browser window, its direction is reversed.

This project is useful for learning **JavaScript functions, arrays, DOM manipulation, image switching, conditional statements, and timers**.
